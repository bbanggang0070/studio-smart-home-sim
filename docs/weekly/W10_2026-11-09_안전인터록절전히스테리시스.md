## 4. 완료 기준 (DoD)

### 센서리스 안전
- [ ] **리플 위치 추정 오차 ≤ 5 mm** (1회 왕복 누적), 하드 스톱에서 재동기화 확인
- [ ] **Zone A–D 전환이 설계값대로 100 % 정확히 라벨링**된다 — 2026-10-12 물리 모드: 리플 추정 위치 기준 라벨이 참값 기준과 99.55 % 일치 (경계 부근 추정 오차만큼 어긋남 — 100 % 기준 재검토 필요)
- [x] **토크 프로파일이 실제 조인트 구동력에 반영**된다 (기동 구간 토크 > 주행 구간) — ✅ 2026-10-12 기동 100 % · 주행 평균 64 % (드라이브 maxForce)
- [x] ⭐ **강체 장애물 끼임 시 감지 성공 · 최대 접촉 반력 ≤ 100 N** — ✅ 2026-10-12 로컬 차단 64 N → 상위 반전 50 mm
- [x] ⭐ **연질·탄성 물체에서도 감지 성공** — 가장 어려운 조건 — ✅ 2026-10-12 쿠션 41 N · 스펀지 40 N
- [x] ⭐ **엔드존(씰 압착)을 끼임으로 오판하지 않는다** — 정상 폐쇄 20회 연속 무오검출 — ✅ 2026-10-12 오검출 0회
- [x] **엔드존 직전에 끼임을 주입하면 검출된다** — 미검출 방지 확인 — ✅ 2026-10-12
- [x] 끼임 후 50 mm 반전 → `SAFETY_HOLD` 진입 → 2회 반복 시 방향 잠금 — ✅ 2026-10-12 (해제 `WINDOW_UNLOCK`)
- [x] MANUAL 모드에서도 끼임 감지가 동작한다 — ✅ 2026-10-12 물리 모드 X4 (감지 · 반전 · 거부 알림 `W_PINCH`)
- [x] ⭐ **제어기 노드를 죽인 상태에서도 로컬 컷오프가 창문을 정지시킨다** (2계층 분리 증거) — ✅ 2026-10-12 제어기 없이 브릿지 + 안전 노드만으로 시험 (`tools/ros/window_safety_test.py`)
- [x] **상위 무응답 500 ms 경과 시 로컬이 정지 상태를 유지한다** — ✅ 로컬은 반대 방향 지령 전까지 같은 방향 재지령 거부 (W06 `bridge_test` · 시간 제한 없음) · 상위 반전이 3 s 안에 안 끝나면 SAFETY_HOLD

### 실험 하네스
- [x] ⭐ **시나리오 40개 × baseline × 반복 = 240개 조합이 전개된다** (물리 39 + 고속 201 — B5 는 Baseline B 대비 포함)
- [ ] **무인으로 연속 10회 이상 실행되고 중간에 죽지 않는다** — 고속 모드 ✅ 2026-10-09 (15회 · 약 4초), 물리 모드 미착수
- [ ] **같은 시드로 2회 실행 시 결과가 동일하다** (재현성) — 고속 모드 ✅ 2026-10-09 (`tests/test_harness.py`), 물리 모드 미착수
- [x] `pass_criteria`가 자동 평가되어 PASS/FAIL이 기록된다 — ✅ 2026-10-09 (PASS/FAIL/PENDING/ERROR/N/A · `results/summary.csv`)
- [ ] `results/summary.csv`에 지표 16종이 집계된다 — 2026-10-12 14종 (#2 응답 시간 · #16 허용 손실 예산 미구현)

### 절전·히스테리시스
- [ ] 문 닫힘 후 판정 창 3분 동안 사람 증거가 없으면(빈방 고정) 전 액추에이터가 절전 상태로 전환 (B4: 180 ± 2 s)
- [ ] 온도가 27~29 °C를 오갈 때 창문/팬 토글이 발생하지 않음 — 부분 ✅ 2026-10-10 고속 모드 (C5 전환 21회 vs Baseline B 7,156회 · 에어컨 승격 · 실링팬 속도 히스테리시스)
- [ ] 습도가 65~72 %RH를 오갈 때 토글이 발생하지 않음
- [ ] 조명 모드가 경계 시각에서 반복 전환되지 않음
- [ ] 단위 테스트 전체 통과

| **엔드존과 끼임이 구분되지 않음** | 오검출 또는 미검출 | 3조건(위치·기울기·지속거리) 중 **"발생 위치" 조건이 최종 판별자**. 엔드존은 행정 종단으로 한정되므로 중간 지점의 완만한 상승은 무조건 끼임으로 처리 |
| **연질 물체에서 반력 상승이 너무 완만** | 감지 실패 | 속도 저하 조건(`speed_drop_ratio`)의 비중을 높인다. 전류만으로 안 되면 속도가 판별한다 |
| **리플 카운팅이 드리프트로 발산** | 위치 추정 붕괴 | 하드 스톱 재동기화 필수. `miscount_rate_pct`를 0.3 % 이하로 제한.<br>**백업 플랜:** 오차가 목표(5 mm)를 넘으면 **홀센서(A3144)+자석 2개(약 3,000원)** 추가 (`hall_reference_enabled: true`) |
| **적응형 임계값이 끼임 상태를 학습해버림** | 감지 무력화 | `exclude_pinch_runs: true` — 끼임이 발생한 주행은 학습에서 반드시 제외 |
| 히스테리시스 폭이 너무 넓어 쾌적성 저하 | 환경 유지율 하락 | 밴드 폭을 파라미터화해 W11 실험에서 비교 |
