## 4-1. 후속 결정 — 재실 센서 (2026-10-05)

| 검토 | 결론 |
|---|---|
| **mmWave를 Wi-Fi CSI로 대체할 수 있나** | ❌ **mmWave 사용 확정 (팀 결정 2026-10-05)**. 호흡 대역 필터링을 재검토했으나 빈방 저주파 잡음 · 옆집 호흡 · 반려동물 · 위치 사각지대는 주파수로 분리되지 않고, 단일 안테나 ESP32는 2–4 m 한계. 문 센서 도입으로 재실 판정만은 CSI 움직임 감지로 대체 가능성이 생겼으나 위치(AUTO 모드) · 수면 판단을 잃는다. CSI는 움직임은 잡지만 **가만히 있는 사람 · 수면은 신뢰할 수준이 아니다** (통제 재현에서 AUC ≈ 0.58, 연구실 조건 87.5 %). 위치(책상/침대) 구분도 불가. 확장 후보로만 기록 |
| **Bluetooth (휴대폰 · 워치)** | ❌ 제외. 절전 상태에서 인식 불가 |
| **상용 스마트홈은 어떻게 하나** | 집 단위(휴대폰 위치 · Wi-Fi · 기기 조작) + 방 단위(PIR → mmWave 융합) 두 층. Wi-Fi · RF 센싱 상용품(Hue · Plume)은 정지한 사람을 못 잡는다 |
| **가전 내장 레이더** | LG · 삼성 고급 시스템에어컨, Nest Hub, TCL TV 등에 있으나 **원룸 보급형 가전에는 없음** → 의존하지 않음 |
| **미세먼지 센서 vs 청정기 · 실링팬 내장 센서** | 청정기 내장 센서는 리모컨 제어로 값을 읽을 수 없고 · 꺼지면 함께 꺼지며 · 위치 편향이 있다. 보급형 실링팬에는 조도 센서가 없다 → **온습도 · 밝기 · 미세먼지 센서 유지** |
| **CO₂ 계산(가상 CO₂) → 재실 기본 환기** | ✅ **변경 (v3.4, 2026-10-06)** — 레이더는 사람 수를 모르고 · 사용자 입력은 불편 · 가스 연소 · 활동량 등 누락. **CO₂를 재지도 계산하지도 않고 1인 기준 환기량을 재실 중 상시 공급**, 환기가 꼭 필요한 순간(요리 · **샤워** · 빨래)은 이벤트로. 비 오면 배기 정지는 **이슬점 비교(I10)** 로 교체, 창문 · 흡기가 막힐 때 회복 원칙 R1–R4. 향초 · 청소는 감지 방법이 불명확해 **추가하지 않음** → [`07` §3.3–3.5](../07_modes_rules_events.md) |
| **미세먼지 센서 + 후드 아래 온도** | ✅ **채택 (v3.3, 2026-10-06)** — 원룸은 청정기가 없거나 센서 없는 저가형이 많아 미세먼지 센서 유지. 후드 아래 온도(~2,000원)로 **가스 · 빌트인까지 요리 감지** · 두 센서로 **미세먼지 원인 구분**(후드는 열 + 연기일 때만) · **불 켜고 외출 경고**. 업계 사례: 열 감지 후드 · Safera Sense(온도 + 공기질) · iGuardStove → [`08` §2.3](../08_multisignal_energy.md) |
| **문 열림 센서 + 호텔 로직** | ✅ **채택 (v3.2)** — 재실은 문이 열릴 때만 바뀐다. 외출 확정 15분 → 3분, 수면 · Wi-Fi 끊김 오판이 원리적으로 사라짐. 문 센서 이상 시 24시간 융합으로 폴백 → [`08` §1.0](../08_multisignal_energy.md) |

## 6. 추가 제안 — 팀원 안보다 나은 방향

| # | 제안 | 왜 더 나은가 | 반영 |
|---|---|---|:---:|
| **P1** | **'존재의 주파수'는 소리가 아니라 호흡(0.2–0.33 Hz)이다** | 피드백 ②에 대한 가장 정확한 답. 소리는 조용한 사람을 못 보고, 호흡은 자는 사람도 본다 — 그리고 mmWave가 이미 그 신호를 쓴다 | ✅ §1.3 |
| **P2** | **mmWave 유지 + Wi-Fi로 PIR 대체** | 팀원 안의 허용 오차 *"휴대폰을 두고 나가면 집에 있음으로 남는다"* 까지 잡는다 | ✅ |
| **P3** | **가상 CO₂를 '보수적으로 높게' 추정하고, NDIR 제거 여부를 오차 지표로 결정** | *"센서를 뺐다"* 가 아니라 *"빼도 되는지 측정했다"* — 발표 설득력 | ✅ 지표 #14 → **v3.4 대체**: 사람 수를 몰라 추정 자체가 불확실 — CO₂를 볼 필요가 없게 기본 환기로 설계 · #14는 습도 회복 시간 |
| **P4** | **계량 스마트 플러그 = 측정 + 제어 + 220 V 안전** | 클램프 안의 안전 문제와 v3.0 릴레이 한계를 동시에 해결 | ✅ |
| **P5** | **쿡탑 전력 → 후드 선제 기동** | 연기가 나기 전에 후드를 켜 PM 피크 자체를 낮춘다 | ✅ |
| **P6** | **우선 목표 + 허용 손실 예산** (빨래만이 아닌 일반 구조) | 피드백 ④를 특수 케이스 코드가 아니라 **이벤트 선언 + 중재 규칙**으로 일반화. 모든 Tier 2 시나리오에 우선 목표 · 감수 손실을 명시 | ✅ |
| **P7** | **제습기 발열 모델 정정** (전력 + 응축 잠열 ≈ 480 W) | v3.0의 200 W는 과소 추정 — C13 · C15 결론의 물리 근거가 강해짐 | ✅ |
| **P8** | **질문마다 맞는 모델 — LSTM은 검토 후 제외** | 데이터가 적고, 하지 않은 전략의 에너지를 계산해야 하며, 귀가 분포가 필요하다 → 회색상자 열모델 · 분위수 회귀 · 변화점 회귀 | ✅ |
| **P9** | **기대비용 최소화 프리쿨링** | 고정 분위수 대신 `에너지 + λ·불쾌 시간` 의 기대값 최소화 — 귀가가 불확실한 날은 자동으로 일찍 | ✅ |
| **P10** | **마르코프 재실 생성기 + 참값 3R3C / 제어용 2R2C 분리** | 12주 데이터를 확보하면서 '자기 답을 자기가 맞히는' 순환 논증을 줄인다 | ✅ |
| **P11** | **전력 한도 규칙** | 원룸 차단기 용량은 실제 생활 문제 — 인덕션 + 에어컨 동시 사용 | ✅ C17 |
| **P12** | **누진 구간 방어** (하계 300 / 450 kWh) | 한국 원룸 요금 구조를 겨냥한 에너지 목표 | ✅ 선택 · 기본 비활성 |
| P13 | NILM — 분전반 CT 1개로 기기별 전력 분해 | 플러그 여러 개 대신 1개. 단 임대 원룸 분전반 접근 · 소부하 정확도 문제 | 📌 확장 |
| P14 | Wi-Fi 센싱 (IEEE 802.11bf, 2025 발행) | 공유기 전파로 재실 · 호흡까지 — 장기적으로 mmWave 대체 후보 | 📌 확장 |
