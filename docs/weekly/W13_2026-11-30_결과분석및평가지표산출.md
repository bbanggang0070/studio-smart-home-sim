## 2. 산출할 평가 지표 8종

| # | 지표 | 정의 | 목표 |
|---|---|---|---|
| 1 | 환경 목표 유지율 | 조도 250–700 lux · 온도 22–28 °C · **습도 40–70 %RH** 유지 시간 비율 | 협조 제어 > 단일 제어 |
| 2 | 응답 시간 | 조건 변화 → 액추에이터 목표 도달 시간 | 조명 ≤ 1 s, 창문 ≤ 5 s |
| 3 | 명령 추종 오차 | 목표 개방률/각도/RPM vs 실제 조인트 상태 | 개방률 ±2 %, 각도 ±3° |
| **4** | **끼임 감지 성공률 / 오검출률** | 장애물 상황 감지 비율 / 정상 주행 중 오정지 비율 | **100 % / 0 %** |
| **5** | **최대 접촉 반력** | 끼임 시 조인트에 실린 최대 힘 | **≤ 100 N** (FMVSS 118 참조) |
| **6** | **리플 위치 추정 오차** | 추정 위치 vs 조인트 ground truth | ≤ 5 mm (1회 왕복 누적) |
| 7 | 절전 제어 효과 | 조명 점등 시간·팬 가동 시간 감소율 | 20 % 이상 감소 |
| 8 | 불필요 구동 횟수 | 히스테리시스 전후 반복 전환 횟수 | 50 % 이상 감소 |

### T13.7 반드시 다뤄야 할 한계 4가지

> 은폐하면 심사에서 더 크게 지적받는다. **먼저 제시하는 것이 강하다.**

| # | 한계 | 서술 방향 |
|---|---|---|
| 1 | **접촉 전 예방이 불가능하다** | 초음파 방식과의 안전 등급 차이를 명시. 목표는 예방이 아닌 **피해 최소화(≤100 N)** 였음을 분명히 한다 |
| 2 | **저속에서 감지 성능이 떨어진다** | 토크 스윕 곡선으로 트레이드오프를 정량 제시. 55 % 선택의 근거를 데이터로 |
| 3 | **연질 물체가 가장 어렵다** | 강성별 감지율표로 제시. 속도 저하 조건이 어떻게 보완하는지 분석 |
| 4 | **리플은 합성값이다** | 무엇이 물리 검증(반력·접촉력)이고 무엇이 모사(리플 카운팅)인지 **표로 명확히 구분**. 신뢰 범위를 스스로 한정한다 |
