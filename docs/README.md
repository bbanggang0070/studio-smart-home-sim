## 시스템 구성 (v3.3)

### 센서 7종 + 비센서 신호

| 센서 | 부품 | 역할 |
|---|---|---|
| 온습도 | DHT22 | 냉방 · 제습 · 가습 · **이슬점 · 결로** |
| 밝기 | BH1750 | 조명 · 블라인드 (책상면은 **추정**) |
| 레이더 재실 | LD2410 (mmWave) | 판정 창 재실 확인 · **위치 → 자동 모드** · 수면 · 자동 보정 |
| **문 열림** | 리드 스위치 | **재실 판정 시점** (호텔 로직) · 귀가 |
| 창문 모터 전류 | ACS712 | 끼임 · 위치 추정 (센서리스) |
| 미세먼지 | PMS7003 | 실내 공기 상태 · **원인 구분** |
| **후드 아래 온도** | DS18B20 | **요리 감지(가스 · 빌트인 포함)** · 불 켜고 외출 경고 |
| 비센서 신호 | 휴대폰 Wi-Fi · 기기 전력 · 날씨 공공데이터 | 귀가 · 기기 상태 · 강우 · 외기 PM — **0원 또는 제어 겸용** |

> 이해용 요약: [09_signal_actuator_map.md](09_signal_actuator_map.md) · 부품비 v3.3 약 137,300원 (계량 플러그 구성 약 168,300원)

### 액추에이터 11종 — 52,900원

| 설치 5종 (단다) | 보유 가전 연결 6종 (연결한다) |
|---|---|
| 창문(센서리스) · 블라인드 · 배기팬 · 책상 스탠드 · **흡기팬+필터** | **실링팬 — 조명 일체형**(조명 PWM · 팬 릴레이) · **에어컨**(IR) · **제습기**(릴레이) · **가습기**(릴레이) · **공기청정기**(IR 공유) · **레인지후드**(릴레이) |

> 천장 조명은 **조명 일체형 실링팬**이 대체한다(조명 + 대류). 제습기 · 가습기는 **별개 2종**이며 상호배제 규칙(I1)으로 묶인다.

### 제어 구조

```text
사용자 → 모드(의도) · 센서 → 이벤트(상황) · 설계자 → 규칙(방법)
     → 수단 사다리 → 6계층 중재(L0 보호 > L1 안전 > L2 건강·재산 > L3 절전 > L4 모드 > L5 쾌적 > L6 조도) → 출력
```
