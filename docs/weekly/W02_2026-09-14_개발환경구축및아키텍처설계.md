## 0. 작업 환경 이관 (주 초반 최우선)

W01까지는 노트북에서 문서 작업만 했다. Isaac Sim은 RTX GPU가 필수이므로 **이번 주부터 데스크톱에서 작업한다.**

### 0.1 대상 장비

| 항목 | 사양 | 비고 |
|---|---|---|
| GPU | **NVIDIA GeForce RTX 5070 Ti** | Blackwell 세대, VRAM 16 GB |
| VRAM | 16 GB | Isaac Sim 권장 사양 충족 |

### 0.2 이관 체크리스트

- [ ] W01 산출물 동기화 (`docs/`, `config/`) — 노트북 → 데스크톱
- [ ] **GPU 드라이버 최신화** — RTX 50 시리즈(Blackwell)는 구버전 드라이버에서 인식되지 않는다. `nvidia-smi`로 드라이버 버전과 CUDA 버전 확인
- [ ] **Isaac Sim 버전이 RTX 50 시리즈를 지원하는지 릴리스 노트에서 확인** ⚠️
  - Blackwell은 비교적 최근 아키텍처라, 구버전 Isaac Sim / PhysX 빌드에서 커널 미지원 오류가 날 수 있다
  - **설치 전에** 공식 릴리스 노트의 지원 GPU 목록을 확인하고, 지원되는 최신 버전을 선택할 것
  - 문제 발생 시 증상: 실행 시 CUDA 커널 오류, RTX 렌더링 초기화 실패, 물리 시뮬레이션 미동작
- [ ] **Effort Sensor API 가용성 검증** ⚠️ — 설치한 버전에서 `isaacsim.sensors.experimental.physics.EffortSensor` 경로가 존재하는지 확인
  - **센서리스 창문 제어(v2.0의 핵심)가 이 API에 전적으로 의존한다.** 없으면 설계를 되돌려야 하므로 첫 주에 확인한다
  - 대체안: `ArticulationView.get_measured_joint_forces()` / `get_measured_joint_efforts()` (`enable_dof_force_sensors=True` 필요)
  - 최소 검증: Prismatic 조인트 하나를 만들어 벽에 밀어붙였을 때 힘 값이 올라가는지
- [ ] 노트북에는 문서 편집 환경만 유지 (이후 시뮬레이션 작업은 데스크톱 전용)

> **이 체크리스트가 W02 최대 리스크다.** 드라이버·버전 문제로 막히면 전체 일정이 밀리므로, 월요일에 가장 먼저 처리한다.
