## 1. 주차 목표
가상 센서 4종을 ROS 2 노드로 구현해 주기적으로 발행하고, 중간 점검에서 폐루프 직전 상태를 시연한다.

> ### 📌 v1.0에서 바뀐 것
> | | v1.0 | **v2.0** |
> |---|---|---|
> | 재실 | PIR 단독 (트리거 볼륨 1개) | **PIR + mmWave 융합** + 영역 구분 |
> | 창문 안전 | 초음파 Raycast 5개 → `window_clearance` | **Effort Sensor → 전류 합성** → `window_motor_current` |
> | 조도 | 단순 계산값 | **W05 캘리브레이션 값 적용** + 책상 조도 추정 |
> | 온습도 | 온도 위주 | **습도 동등 취급** (시나리오 C1·C6) |

### T7.3 재실 융합 로직

```text
상태 머신:
  VACANT ──(PIR 트리거)──────────────→ OCCUPIED      # 입실: PIR이 빠르게 개시
  OCCUPIED ──(mmWave 감지 지속)──────→ OCCUPIED      # 유지: 정지 인체 커버
  OCCUPIED ──(PIR·mmWave 모두 클리어 + 60 s)─→ VACANT

교차 검증 (오검출 기각):
  mmWave만 감지 + 직전 입실 이벤트 없음  →  재실로 인정하지 않는다
  (커튼 흔들림, 벽 투과로 잡힌 옆방 사람을 걸러낸다)
```

| 파라미터 | 값 | 출처 |
|---|---:|---|
| `vacancy_timeout_s` | **60.0** | v1.0의 300초에서 단축 — mmWave가 정지 인체를 잡으므로 |
| `pir_debounce_s` | 1.0 | 입실 이벤트 채터링 방지 |
| `mmwave_hold_s` | 3.0 | 신호 일시 유실 허용 |
| `zone_debounce_s` | 2.0 | 영역 전환 채터링 방지 |

### T7.4 전류 합성

```python
def read_motor_current() -> float:
    F = abs(effort_sensor.get_sensor_reading().value)     # [N] 조인트 반력
    tau_m = F * R_PINION / (ETA * GEAR_RATIO)             # [N·m] 모터 토크
    return tau_m / K_T + I_NO_LOAD                         # [A]
```

> ⚠️ **리플은 물리 엔진으로 재현할 수 없다.** 리플 주파수가 239 Hz로 물리 스텝을 초과하기 때문이다.
> 조인트 각도의 함수로 **해석적으로 합성**한다. 근거와 한계는
> [`04_sensorless_window_control.md` §4.3](../04_sensorless_window_control.md) 참조.
>
> 위치 추정에는 **양자화(0.209 mm) + 미스카운트(0.3 %) + 가우시안 노이즈**를 주입해
> 실제 센서리스 추정의 불확실성을 재현한다. 하드 스톱에서 재동기화한다.

## 4. 완료 기준 (DoD)
- [ ] 센서 토픽이 규정 주기로 안정 발행 (일반 10 Hz / 전류 50 Hz / 위치추정 20 Hz)
- [ ] ⭐ **사람 프록시가 책상에 정지해 있어도 `occupancy`가 true를 유지한다** — mmWave 유지 동작 증거
- [ ] ⭐ **mmWave 영역만 반응하고 입실 이벤트가 없으면 재실로 인정하지 않는다** — 교차 검증 증거
- [ ] 프록시를 desk ↔ bed로 옮기면 `occupant_zone`이 정확히 전환된다
- [ ] ⭐ **창문을 장애물에 밀어붙이면 `window_motor_current`가 상승한다**
- [ ] **장애물 없이 왕복 시 전류가 Zone A(피크) → B(평탄) → C(램프) → D(급증) 패턴을 보인다**
- [ ] **`window_position_est`가 실제 개방률을 ±5 mm 이내로 추종하고, 하드 스톱에서 재동기화된다**
- [ ] 조도 발행값이 W05 캘리브레이션과 일치한다
- [ ] 중간 점검 발표 완료 및 피드백 정리

## 5. 리스크 / 대응
| 리스크 | 대응 |
|---|---|
| **Effort Sensor 반력이 노이즈로 요동** | 저역통과 필터 적용. 필터 시정수를 너무 크게 잡으면 끼임 감지가 늦어지므로 `debounce_ms`(30 ms)와 정합시킨다 |
| **리플 합성 오버샘플링이 성능을 잡아먹음** | `oversample`를 8 → 4로 축소. 전류 발행 50 Hz는 유지한다 |
| **리플 위치 추정이 드리프트로 발산** | 하드 스톱 재동기화를 반드시 구현. 미스카운트율을 0.3 %보다 크게 주면 검증이 불가능해지므로 상한을 둔다 |
| **재실 융합이 입실을 놓침** (PIR 트리거 미발생) | 출입선 트리거 볼륨의 두께를 키워 빠르게 통과해도 잡히게 한다. 보조로 mmWave 근거리 게이트를 입실 힌트로 사용 |
| mmWave 영역 경계에서 채터링 | `zone_debounce_s` 2초 + 영역 간 히스테리시스 |
| 중간 점검 준비가 구현을 잠식 | 발표는 **현재 동작하는 것만** 보여준다. 미완 항목은 계획으로 제시 |
