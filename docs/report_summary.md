# 요약판 — 1인 가구 원룸을 위한 저가형 스마트홈 다중 액추에이터 협조 제어

## 1. 문제와 목표
원룸은 요리 · 빨래 · 수면 · 공부가 한 공간에서 일어나 실내 환경 목표가 자주 충돌한다 — 후드를 켜면 음압으로 바깥 미세먼지가 들어오고, 제습기를 켜면 방이 더워지며, 가습하면 창에 결로가 생긴다. 상용 스마트홈은 기기마다 따로 움직여 이런 충돌을 다루지 못한다.
**목표**: 이미 있는 가전 6종과 저가 장치 5종(부품비 약 137,300원 · 가전 구매 0원)을 센서 7종 · 비센서 신호 3종으로 묶고, 제약이 한 수단을 막으면 다음 수단으로 넘어가는 협조 제어기를 만들어 검증한다.

## 2. 방법
- **제어기**: 규칙 10개 · 이벤트 15종 · 사용자 모드 6종 · 6계층 중재 · 목표별 수단 사다리 (보고서 §3 그림 A · B)
- **센서리스 창문**: 모터 전류 리플로 위치를, 리플 · 반력으로 끼임을 판단 → 즉시 정지 · 반전
- **두 실행 모드**: 물리(Isaac Sim · 시나리오 8개) / 고속(환경 모델 · 33개) — 제어기 · 센서 특성 · 가전 보호는 같은 코드
- **비교 대상**: A 기기별 내장 자동 · **A′ 상용 허브 수준 규칙 자동화** (결과 보기 전 명세) · B 히스테리시스 없음
- **평가 신뢰성 장치**: 판정 동결 · 무작위 반복 · 서울 2024 실측 기상 · 사전 등록 보류 평가 7차 · BOPTEST · 판정 3분류(환경 결과 · 수단 · 과정 — 기준선 비교는 환경 결과로) · 시나리오 묶음 부트스트랩 · 센서 결함 · 임계값 ±20 % · 물리 조건 무작위

## 4. 한계 (핵심)
1. **실측 없음** — 모델 · 계수 · 센서 특성은 문헌 · 가정값. 실제 원룸의 절감률 · 정확도를 주장하지 않는다
2. **판정 기준 · 시나리오 · 제어기를 같은 사람이 만들었다** — 동결 · 사전 등록 · 3분류로 줄였지만 없애지 못했다
3. **에너지 절감은 확정하지 못했다** — 주장은 '같은 쾌적을 더 싸게'
4. **센서 편향에 약하다** — 습도 편향이 이슬점 비교(I10)를 흔든다
5. **끼임 반전 거리 50 mm** — 차량 표준의 100 N 기준만 빌렸고 반전 거리 요건은 충족하지 않는다
6. **외출 냉방 계획기** — 긴 외출(8시간)에서 '끄기' 보다 24–66 % 비싸다. 제어기는 바꾸지 않았다 (사용자 결정 2026-10-28)
7. **장비 한계** — 흡기팬 60 m³/h ≪ 후드 배기량 (큰 흡기는 효과가 크지만 비용 · 설치 · 소음 부담)

## 5. 결론
협조 제어기는 목표가 충돌하는 원룸에서 상용 허브 수준 자동화보다 실내 환경 결과를 크게 더 잘 지켰고, 같은 쾌적을 약 30 % 낮은 기대비용으로 얻었다. 처음 보는 조합 · 센서 결함 · 물리 조건 변동에서도 83–89 % 를 유지했다. 반면 에너지 절감은 확정하지 못했고 결과는 시뮬레이션이다. 평가 장치를 하나씩 더할 때마다 제어기 결함과 과장된 비교가 드러났다 — 현실적인 기준선과 실제 시스템 조건을 하네스에 넣는 것이 결정적이었다.

**향후**: 실제 원룸 측정으로 모델 보정 · 독립 작성자의 보류 시나리오 · 센서 편향에 강한 판단 · 외출 냉방 계획기 개선
