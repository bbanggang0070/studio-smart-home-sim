# W11 주차 계획서 — Tier 1 전체 + Tier 2 전반 실험

- **기간:** 2026-11-16(월) ~ 2026-11-22(일)
- **단계:** Phase 4. 실험·검증
- **개정:** 2026-09-12 · v2.0 — S1–S4(4개) → **B1–B5 + C1–C4 (9개 시나리오 / 51회 실행)**

## 1. 주차 목표

**Tier 1 기본 동작 5개**로 회귀 검증을 마치고, **Tier 2 제약 충돌 전반 4개**를 3군 비교로 실행한다.
특히 **C1(고온다습+우천)** — 발표 피드백에서 직접 지목된 대표 시나리오 — 의 데이터를 확보한다.

## 2. 실험 대상

### Tier 1 · 기본 동작 (Proposed 단독 × 3회 = 15회)

| ID | 조건 | 기대 결과 | 확인 지표 |
|---|---|---|---|
| B1 | 재실, 180 lux, 23 °C | 천장 조명 비례 점등 | 조도 응답 시간 · 추종 오차 |
| B2 | 재실, 850 lux | 블라인드 차광 → 조명 소등 | 블라인드 목표각 오차 |
| B3 | 재실, 30 °C, 환기 가능 | 블라인드 → 창문 40 % → 팬 저속 | 냉각 정책 순서 |
| B4 | 문 닫힘 후 판정 창 3분(180 s) 경과 · 사람 증거 없음 | 전 액추에이터 절전 | 절전 전환 정확도 |
| B5 | 온도 28↔25 °C 반복 진동 | 토글 억제 | 불필요 구동 횟수 |

### Tier 2 전반 · 제약 충돌 (A/B/Proposed × 3회 = 36회)

| ID | 충돌 제약 | 기대 협조 동작 | 핵심 확인 |
|---|---|---|---|
| **C1** ⭐ | 환기 필요 ↔ 우천 | 창문 폐쇄 유지 · **팬 최대** · 블라인드 차광 | Baseline A는 창문을 열어 **습도가 오히려 상승**해야 함 |
| C2 | 환기 필요 ↔ 끼임 | 접촉 감지 → 정지·반전 → 팬 고속 보상 | **최대 접촉 반력 ≤ 100 N** |
| C3 | 환기 ↔ 일사열 | **블라인드 선행 차광** 후 창문·팬 | 동작 순서가 로그로 증명될 것 |
| C4 | 조도 필요 ↔ 조명 발열 | 천장 밝기 상한 + 스탠드 보충 + 팬 보상 | 조도·온도 **동시** 유지 |

**총 실행: 15 + 36 = 51회**

## 5. 완료 기준 (DoD)
- [ ] **Tier 1 5개가 3회 모두 PASS** — 기본 기능 회귀 없음
- [ ] ⭐ **C1에서 Proposed는 창문을 열지 않고, Baseline A는 열어서 습도가 상승한다** — 대표 사례 성립
- [ ] **C2에서 최대 접촉 반력이 100 N 이하로 기록된다**
- [ ] **C3에서 블라인드 동작이 창문 동작보다 선행함이 타임스탬프로 증명된다**
- [ ] **C4에서 책상 조도 600 lux 이상 + 실내 온도 28 °C 이하가 동시 달성된다**
- [ ] 51회 전부 결측 없이 로깅됨
- [ ] 동일 시드 재실행 시 결과가 재현된다
