### 창문 모듈 프림 구조 (확정)

```text
/World/window/
├── window_frame            (Static)      ← 창틀. 랙(톱니)이 여기에 있다
│   ├── rack_visual         (Mesh)
│   └── seal                (Mesh)        ← 폐쇄 종단 씰 (Zone D)
├── window_panel            (RigidBody)   ← 미닫이 패널
│   ├── panel_glass         (Mesh)
│   ├── motor_unit          (Mesh)        ← 패널에 부착된 모터+피니언 외형
│   └── contact_sensor      (Contact)     ← 접촉 반력 검증용
└── window_prismatic_joint  (Prismatic)   ← 제어 대상
    └── effort_sensor       (Effort)      ← 반력 → 전류 환산 입력
```

> ✅ **v1.0의 `safety_distance_zone`(Raycast 감지 영역)은 삭제되었다.**
> 초음파 센서를 제거했으므로 감지 영역 프림도, `window_frame` 씬 쿼리 제외 처리도 더 이상 필요 없다.

## 4. 완료 기준 (DoD)
- [ ] Scene을 열었을 때 물리 시뮬레이션이 안정적으로 실행(오브젝트 낙하/진동 없음)
- [ ] 프림 계층 구조가 위 창문 모듈 구조와 일치
- [ ] **패널을 수동으로 밀어 씰에 닿게 하면 Contact Sensor에 반력이 잡힌다** — 엔드존 보상 검증의 전제
- [ ] **끼임 테스트 물체 3종을 레일 경로에 배치할 수 있고, 패널과 실제로 충돌한다**
- [ ] **재실 영역**(현관문 열림 / desk·bed 게이트)이 정의되어 문 열림과 프림 진입·이탈이 판정된다
- [ ] **조명 2종**(천장·스탠드)이 각각 독립적으로 밝기 변경되고, 스탠드 광원이 책상면을 비춘다

## 5. 리스크 / 대응
| 리스크 | 대응 |
|---|---|
| 에셋 폴리곤 과다로 FPS 저하 | 저폴리 프록시 사용, 시각 전용 메시는 충돌 제외 |
| 원룸 치수 근거 부족 | 국내 원룸 표준 면적(약 17~20 m²) 기준 명시 |
| **접촉 반력이 튀거나 물체를 관통** | solver iteration 상향, 물체 질량·마찰 계수 현실값 설정. **끼임 실험의 신뢰도가 여기서 결정된다** |
| **씰 압착 마찰이 너무 약해 엔드존 램프가 생기지 않음** | 씰 머티리얼의 마찰 계수를 조정해 **완만한 전류 상승**이 재현되도록 튜닝. Zone C/D 검증 불가 시 W10이 막힌다 |
| 재실 영역 경계가 가구와 겹쳐 오판 | desk/bed 영역을 mmWave 거리 게이트(0.75 m 단위)와 일치하도록 배치 |
