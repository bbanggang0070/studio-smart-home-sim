# 실험 시나리오 명세서 (Scenario Specification)

> 작성일 2026-09-12 · v1.0 → v1.1 (C8 추가) → 2026-10-05 v2.0 (기획 v3.0) → **2026-10-05 · v2.1 (피드백 2 반영)**
> **v1.0 배경:** W01 발표 피드백 ① *"시나리오가 너무 단편적이고 적어서 협력 제어를 잘 반영하지 못한다"* — S1–S7 → 17개 3계층

> **v2.5 배경:** CO₂ 측정 · 계산 폐지 → **재실 기본 환기** · **샤워(E3)** · **창문 · 흡기가 막힐 때 실내 환경 회복** — **38개 → 40개** (B6 · C11 · C12 · X6 개정, C18 · C19 신설)
> (설계: [`06`](06_appliance_integration.md) · [`07`](07_modes_rules_events.md) · [`08_multisignal_energy.md`](08_multisignal_energy.md))

## 1. 재설계의 원칙

### 1.1 왜 S1–S7이 협조 제어를 못 보여줬나 (v1.0 진단 — 유지)

| 기존 ID | 조건 개수 | 움직이는 액추에이터 | 협조 발생 여부 |
|---|---:|---:|---|
| S1 저조도 | 1 | 1 | ❌ 단일 매핑 |
| S2 과조도 | 1 | 2 | △ 순차 동작일 뿐 |
| S3 고온 | 1 | 3 | △ 역할 분담은 있으나 충돌 없음 |
| S4 고온+장애물 | 2 | 2 | ✅ 유일한 협조 사례 |
| S5 무재실 | 1 | 4 | ❌ 전부 OFF — 조율 없음 |
| S6 경계 진동 | 1 | 2 | ❌ 히스테리시스 검증 |
| S7 수동+장애물 | 2 | 1 | △ 안전 검증 |

**7개 중 실제로 협조 제어가 관찰되는 것은 S4 하나뿐이었다.**

### 1.2 핵심 원칙

> **협조 제어는 "제약이 서로 충돌할 때"만 관찰된다.**

v2.0에서 가전이 늘면서 **충돌의 종류도 늘었다.** 새로 생긴 충돌 유형은 다음과 같다.

| 새 충돌 유형 | 예 | 시나리오 |
|---|---|---|
| **국소 배기 ↔ 음압 유입** | 후드를 켜야 하는데 외기가 오염됐다 | C9 · X5 |
| **가습 ↔ 결로** | 건조해서 가습해야 하는데 창에 물이 맺힌다 | C10 |
| **냉방 ↔ 환기** | 에어컨 효율을 위해 닫아야 하는데 기본 환기는 계속해야 한다 | C11 |
| **환기 ↔ 소음** | 자는 중에도 기본 환기는 해야 하는데 팬을 키울 수 없다 | C12 · X6 |
| **제습 수단 ↔ 발열** | 같은 제습이라도 제습기 발열이 여름엔 독, 겨울엔 득 | C13 |
| **절전 ↔ 재산 보호** | 외출 중인데 습도가 올라 곰팡이 위험 | C14 |
| **명령 ↔ 미확인** | IR을 보냈는데 에어컨이 반응했는지 모른다 | X7 · B11 |
| **우선 목표 ↔ 쾌적 (감수)** 🆕 | 빨래를 빨리 말리려면 방이 조금 더워지는 것을 감수 | **C15** |
| **에너지 ↔ 귀가 시 쾌적** 🆕 | 끄면 아끼지만 귀가 때 덥다 · 켜 두면 쾌적하지만 낭비 | **C16** |
| **동시 사용 ↔ 전력 한도** 🆕 | 요리 + 냉방 + 제습이 원룸 차단기 용량에 닿는다 | **C17** |
| **실내 회복 ↔ 환기 제한** 🆕 (v2.5) | 샤워 · 요리 습기를 빼야 하는데 비 · 외기 미세먼지로 창문 · 배기가 막힌다 | **C18 · C19** · X5 |
| **신호 오판 ↔ 판단 확신** 🆕 | 휴대폰 절전 · 두고 외출 · 수면 중 Wi-Fi 끊김 | B12 · **X9** |

| 계층 | 성격 | 개수 | 역할 |
|---|---|---:|---|
| 🟢 **Tier 1 (B)** | 단일 조건 · 기본 동작 | **12** | 회귀 테스트 — 기능이 깨지지 않았음을 보장 |
| 🟡 **Tier 2 (C)** | 2개 제약 충돌 | **19** | **협조 제어의 본체** — 발표 핵심 근거 |
| 🔴 **Tier 3 (X)** | 3개 이상 / 예외 경계 / 실패 처리 / 일반화 | **9** | 시스템 성숙도 입증 |

### 1.3 우선순위 (v3.0 · 6계층)

```text
L0 로컬 하드 보호 > L1 안전 인터록 > L2 건강·재산 이벤트 > L3 절전 > L4 모드 제약 > L5 쾌적 > L6 조도
```

동일 액추에이터에 여러 요구가 걸리면 **force는 상위 계층 우선 · cap은 최솟값 · need는 최댓값**으로 병합한다.
→ [`07_modes_rules_events.md` §5](07_modes_rules_events.md)

### 1.5 우선 목표와 감수하는 손실 — Tier 2 전수 점검 (피드백 ④)

> **협조 제어는 '모두 만족'이 아니라 '무엇을 지키고 무엇을 감수하는가'의 결정이다.**
> 각 시나리오가 무엇을 최우선으로 두고, 그 대가로 어떤 손실을 **얼마까지** 받아들이는지 명시한다.
> 손실 상한(허용 손실 예산)을 넘으면 실패로 판정한다 — 지표 #16. 구조: [`08` §4](08_multisignal_energy.md)

| ID | 최우선 목표 | 감수하는 손실 | 손실 상한 (예산) |
|---|---|---|---|
| C1 | 습도 · 온도 (우천 방어 유지) | 에너지 — 에어컨 기동 | 없음 (L1 안전 동반) |
| C2 | **안전** (반력 ≤ 100 N) | 냉방 지연 | 없음 (L0) |
| C3 | 열원 차단 | 채광 감소 | 조도 ≥ 250 lux 유지 |
| C4 | 책상 조도 600 lux | 천장 밝기 제한 → 방 전체 밝기 | 온도 ≤ 28 °C |
| C5 | **수면 소음 (N0)** | 냉방 속도 | 온도 ≤ 28 °C (1시간 내) |
| C6 | **결로 해소** | 프라이버시(블라인드 개방) · 난방 손실 | 실내 온도 하락 ≤ 2 °C |
| C7 | 우천 방어 | 절전 상태 일시 해제 | 창문 외 구동 0 |
| C8 | 실내 공기질 | 에너지 — 에어컨 · 흡기팬 | 실내 PM ≤ 35 · 기본 환기 유지 |
| C9 | **요리 PM 피크 저감** | 소음 (N3 임시) | 요리 종료 후 5분 내 N2 복귀 |
| C10 | **결로 방지** | 습도 목표 일부 (60 % 대신 53–59 %) | 최종 RH ≥ 50 % |
| C11 | 기본 환기 40 m³/h (공부) | 냉방 효율 | 에너지 Baseline B 대비 증가 금지 |
| C12 | 수면 소음 (N0) | 환기 여유 (기본량만) | 기본 환기 충족 ≥ 95 % |
| C13 | 에너지 · 온도 | 제습 속도 (제습기 미사용) | 30분 내 RH ≤ 60 % |
| C14 | 곰팡이 방지 | 외출 중 절전 일부 (제습기) | 제습기 외 가동 0 |
| **C15** | **빨래 건조 시간** | **실내 온도 상승 · 에너지 증가** | **재실 +1.0 °C · 외출 +3.0 °C** |
| **C16** | **귀가 시 쾌적** | 프리쿨링 에너지 | 셋백 유지 대비 에너지 증가 금지 |
| **C17** | **전력 한도 (차단기)** | 제습 · 가습 · 냉방 일부 지연 | 후드 · 안전 차단 0 |
| **C18** | **샤워 습기 회복** | 에너지 — 에어컨 제습 강화 · 제습기(I6 해제) · 소음 N2 | 실내 온도 변화 ±1.0 °C · 30분 내 RH ≤ 60 % |
| **C19** | **샤워 · 빨래 습기 회복 + 실내 공기질** | 난방 손실 (겨울 균형 환기) | 실내 온도 하락 ≤ 1.5 °C · 실내 PM ≤ 35 · 결로 0 |

#### C1과 C8 — 같은 "창문 폐쇄", 다른 대체 수단

| | C1 (우천) | **C8 (미세먼지)** |
|---|---|---|
| 외기의 성질 | **습하다** | **오염됐다** |
| 창문 | 폐쇄 | 폐쇄 |
| 배기팬 | 정지 (습기 유입) | **정지 (음압 유입)** |
| **누가 인수하나** | **에어컨 제습** — 외기를 들이는 수단은 모두 무의미 | **필터 흡기팬** — 걸러서 들이면 된다 |
| P-core(가전 없음)라면 | 배기팬이 인수 (v1.1) | 수단 소진 (v1.1) |

> **제약의 성질이 대체 수단을 결정한다.** 습기는 필터로 거를 수 없지만, 먼지는 거를 수 있다.

Tier 1 : 12 시나리오 × 3회 × 1군 =  36회

──────────────────────────────────────────

별도 실험
