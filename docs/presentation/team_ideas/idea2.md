# 클램프 기반 기기 상태 판정 & 에너지 소비 패턴 분석

> 원룸 저가형 스마트홈 협조 제어 — 3주차 발표 피드백 반영 정리

## 0. 받은 피드백

1. **클램프로 전력을 재서 on/off 상태를 확인할 것**
   단순히 전원 버튼(또는 IR 명령)으로 on/off 상태를 확인하려 하지 말 것
2. **에너지 소비량 패턴을 분석할 것**
   외기 온도에 따른 가전제품 에너지 소비 패턴 분석도 포함

두 피드백은 같은 데이터에서 출발한다. **기기별 전류를 실측하면 상태 판정과 에너지 패턴 분석이 동시에 가능하다.**

## 1. 클램프로 기기 on/off 상태 판정

### 1.1 원칙

- 리모컨·IR 명령·전원 버튼으로 "켰으니 켜졌다"고 **가정하지 않는다.**
- CT 클램프로 **실제 전류**를 재서 기기 상태를 판정한다.
- 상태가 **바뀌는 순간(엣지)** 을 제어 트리거로 사용한다.

### 1.2 왜 필요한가

| 효과 | 설명 |
|---|---|
| IR 실패 감지 | ON 명령을 보냈는데 전류가 없으면 재전송 → 에어컨·제습기 제어가 폐루프가 됨 |
| 수동 조작 감지 | 명령 없이 전력이 바뀌면 사용자가 리모컨으로 직접 조작한 것 → R10 규칙(수동 조작은 되돌리지 않고 목표값 오프셋으로)에 활용 |
| 써모오프 구분 | 인버터 에어컨은 설정 온도 도달 시 컴프레서만 멈추고 팬은 계속 돎 → OFF로 오판하면 안 됨 |
| 실측 에너지 | 평가 지표의 에너지를 모델값이 아니라 실측값으로 검증 |

### 1.3 하드웨어

| 부품 | 용도 | 비고 |
|---|---|---|
| CT 클램프 SCT-013 | 비접촉 전류 측정 | 작은 전류(PC 등)는 5 A급, 큰 전류(에어컨 등)는 30 A급 |
| ADS1115 (16 bit ADC) | 전류 신호 디지털 변환 | 차동 입력(A0 신호, A1 바이어스)으로 작은 전류 해상도 확보. 1개당 차동 2채널 → 4개 기기면 2개(주소 분리) |
| 바이어스 회로 | 교류 신호를 ADC 범위 중앙으로 올림 | 저항 분압 |
| 라인 분리 어댑터 | 상선 한 가닥만 분리 | **클램프는 반드시 전선 한 가닥만 감아야 함.** 코드를 통째로 감으면 왕복 전류가 상쇄되어 0 A로 읽힘 |

**안전**
- 측정은 **플러그와 콘센트 사이에서만** 한다.
- 분전반이나 벽 배선은 건드리지 않는다. (220 V, 원룸은 임대 설비)
- 직결 배선 기기(빌트인 가전 등)는 측정 대상에서 제외한다.

### 1.4 신호 처리

1. 860 SPS로 샘플링, 1초 창으로 Irms 계산
   (비동기 샘플링이어도 여러 주기를 평균하면 on/off 판정에는 충분)
2. 이동평균으로 노이즈 제거
3. 다단계 상태로 판정 (단순 on/off가 아님)
4. **히스테리시스 + 지속 시간**으로 상태 확정
   (기동 순간의 돌입전류, 노이즈에 반응하지 않도록)

### 1.5 기기별 상태 정의

> 임계값은 예시이며, 기기별 실측으로 교정해야 한다.

| 기기 | 상태 | 판정 기준 (예시) | 비고 |
|---|---|---|---|
| 에어컨 | OFF | < 0.05 A | |
| | FAN_ONLY (써모오프) | 0.1 – 0.5 A | 목표 온도 도달, 팬만 가동 |
| | RUN (컴프레서 가동) | > 1.0 A | 진입 3초 이상 유지 시 확정 |
| 제습기 | OFF / FAN_ONLY / RUN | 에어컨과 동일 구조 | 가동 중 FAN_ONLY 수준으로 급감 → 물통 가득 추정 |
| PC | OFF·대기 / ACTIVE | 30초 평균 수십 W 이상 → ACTIVE, 2분 이상 하락 → OFF | 대기전력 수 W는 CT로 구분 어려움 → ACTIVE 진입만 판정 |

OFF 확정은 10초 이상 유지될 때만 인정한다.

**가스레인지는 전력으로 측정 불가** → 요리 감지는 연소 신호(주방 재실 + CO2 급등 + 온·습도 상승)로 하고, 레인지후드가 플러그형이면 후드 전력을 보조 트리거로 쓴다.

### 1.6 상태 머신 예시 (의사 코드)

```python
class ApplianceState:
    def __init__(self, th_fan=0.1, th_run=1.0, t_on=3.0, t_off=10.0):
        self.state = "OFF"
        self.candidate, self.since = None, None
        self.th_fan, self.th_run = th_fan, th_run
        self.t_on, self.t_off = t_on, t_off

    def classify(self, irms):
        if irms > self.th_run:
            return "RUN"
        if irms > self.th_fan:
            return "FAN_ONLY"
        return "OFF"

    def update(self, irms, now):
        raw = self.classify(irms)
        if raw == self.state:
            self.candidate = None
            return None
        if raw != self.candidate:
            self.candidate, self.since = raw, now
            return None
        hold = self.t_off if raw == "OFF" else self.t_on
        if now - self.since >= hold:
            prev, self.state = self.state, raw
            self.candidate = None
            return (prev, raw)   # 엣지 이벤트
        return None
```

### 1.7 이벤트(트리거) 설계

상태가 바뀔 때만 이벤트를 발행한다.

```
토픽: /studio/event/appliance
예시: {device: "aircon", edge: "OFF->RUN", irms: 3.2, source: "manual"}
```

| 이벤트 | 조정자 동작 |
|---|---|
| 에어컨 OFF → ON (사용자가 직접 켬) | 창문 닫기, 배기 낮춤, 실링팬 여름 모드 |
| 에어컨 ON → OFF | 외기 조건이 좋으면 창문 환기로 전환 |
| 에어컨 RUN → FAN_ONLY | 목표 온도 도달 → 실링팬 속도 낮춤 |
| PC OFF → ACTIVE + 책상 영역 재실 | 공부 모드 진입 |
| 제습기 RUN → FAN_ONLY (급감) | 물통 가득 추정 → 알림 |

### 1.8 명령-실측 비교 (폐루프)

| 명령 | 실측 | 판정 | 동작 |
|---|---|---|---|
| ON 전송 | 10초 내 전류 증가 | 정상 | — |
| ON 전송 | 10초 내 변화 없음 | IR 실패 | 재전송 (최대 N회 후 알림) |
| 명령 없음 | 전류 변화 | 수동 조작 | 사용자 의도로 해석, 목표값 오프셋 반영 |

`source` 필드로 명령에 의한 변화(`command`)와 수동 조작(`manual`)을 구분한다.

### 1.9 Isaac Sim

- 기기별 전력 프로파일 모델: 에어컨 기동·써모오프, 제습기, PC 부팅 곡선
- 프로파일에 노이즈를 더해 **가상 Irms 토픽**을 발행
- 실물과 **같은 상태 판정 코드**를 시뮬레이션에서 그대로 검증

## 2. 에너지 소비량 패턴 분석

### 2.1 목표

| 분석 | 내용 | 활용 |
|---|---|---|
| 생활 패턴 학습 | 요일·시간대별 기기 사용 확률 | 귀가·기상·요리 시각 예측 → 외출 시 셋백/끄기 판단, 귀가 전 프리쿨링 |
| 외기 온도별 패턴 | 외기 온도에 따른 기기별 소비전력·에너지 | 에너지 예측, S2 전력 한도 사전 대응, 셋백 vs 끄기 손익분기 산출 |
| 이상 감지 | 같은 조건 대비 기준 전력에서 벗어남 | 필터 막힘, 에어컨 효율 저하, 대기전력 증가 |

### 2.2 핵심 가설: 외출 시 에어컨은 끄지 말고 설정 온도를 올려 둔다

**가설**

> 인버터 에어컨은 외출할 때 전원을 끄는 것보다, **설정 온도를 올려 둔 채 계속 운전(셋백)** 하는 쪽이 전력 소비와 전기요금에 유리하다.

**왜 그런가 (원리)**

| 구분 | 끄고 외출 → 귀가 후 재가동 | 설정 온도를 올려 유지 (셋백) |
|---|---|---|
| 컴프레서 | 재가동 시 최대 출력으로 운전 → 효율(COP) 낮음 | 저출력으로 꾸준히 운전 → 인버터 효율이 가장 좋은 구간 |
| 축열 | 공기뿐 아니라 벽·가구·침구에 쌓인 열까지 다시 제거해야 함 | 실내 온도 상승 폭이 작아 축열이 적음 |
| 습도 | 꺼진 동안 습도 상승 → 재가동 시 제습(잠열) 부하 추가 | 운전 중 제습이 계속되어 습도 유지 |
| 귀가 시 쾌적성 | 덥고 습한 상태에서 회복 시간 필요 | 바로 쾌적 범위에 근접 |

인버터 압축기는 필요한 만큼만 회전 속도를 낮춰 운전하므로, 껐다 켜며 최대 출력 구간을 반복하는 것보다 낮은 출력으로 이어서 도는 쪽이 효율이 좋다.

**단, 항상 그런 것은 아니다 (반대 요인)**

- 에어컨이 처리해야 하는 열은 실내·외 온도차에 비례해 들어온다.
- 끄면 실내 온도가 올라가 온도차가 줄고, **들어오는 열 자체가 줄어든다.**
- 따라서 **외출이 길수록 끄는 쪽의 절약분이 재가동 손해보다 커진다.**
- 결국 **외출 시간에 손익분기점이 있다.** 짧으면 셋백·유지, 길면 끄기가 유리하다.

**근거 자료**

| 출처 | 구분 | 내용 |
|---|---|---|
| 한국전력 | 기관 안내 | 인버터형은 껐다 켰다 하는 단속 운전보다 희망 온도를 고정한 연속 운전이 전력 절감에 유리. 26 °C 설정은 24 °C 대비 전력 0.7배 (2시간 가동 기준) |
| 삼성전자 에어솔루션 전문기술랩 | 제조사 실험 | 끄고 30분 뒤 재가동 시 연속 운전보다 +5%, 60분 +2%, 90분을 넘으면 끄는 쪽이 감소 |
| 다이킨 (2016 여름, 오사카) | 제조사 실험 | 낮 35분·밤 18분 이내 외출이면 켜두기가 유리. 30분 외출 후 귀가 시 끈 방이 1 °C 높고 습도 8%p 높음 |
| 다이킨 (2018 겨울, 교토) | 제조사 실험 | 30분 간격 on/off보다 켜두기가 모든 시간대에서 유리, 밤 2시간 외출은 끄기가 유리 |
| MPC for Residential Split AC (2022) | 논문 | 인버터 에어컨을 on/off 제어하면 연속 운전보다 20.12% 더 소비 |
| Occupancy Presence Sensors in a Single-Family Home (Energy and Buildings, 2024) | 논문 | 비재실 시 셋백으로 일일 최대 35% 절감, 외출이 길고 외기 온도가 높을수록 절감 증가 |
| Niknami et al. (Energy and Buildings, 2024) | 논문 | 설정 온도 1 °C 상향 시 약 57 W 감소 → 셋백 폭을 전력으로 환산하는 근거 |

> 제조사·기관 자료는 논문이 아니므로 "참고치"로 표기한다.
> 기존 실험은 대부분 **"같은 설정 온도로 켜두기 vs 끄기"** 비교다.
> **"설정 온도를 올려 유지(셋백) vs 끄기"를 원룸 벽걸이 인버터 에어컨으로 실측 비교한 연구는 찾지 못함 → 본 프로젝트가 검증할 부분.**

**우리 시스템의 제어 규칙 (초안)**

| 조건 | 동작 |
|---|---|
| 예상 외출 시간 < T\* | 설정 온도 +2~3 °C 올려 유지 (셋백) |
| 예상 외출 시간 ≥ T\* | 끄기 → 귀가 예상 30분 전 프리쿨링 |
| 외기 온도가 높을수록 | 셋백 폭을 줄임 (재가동 부하가 커지므로) |
| 수면 중 | 끄지 않고 설정 고정 유지 (stay) + 실링팬 저속 |

- **T\* (손익분기 외출 시간)는 고정값이 아니다.** 제조사 실험만 봐도 18분~90분으로 차이가 크다.
- 외기 온도, 방의 단열·열용량, 에어컨 용량에 따라 달라지므로 **실측과 시뮬레이션으로 우리 방의 T\* 표를 만든다.**
- 예상 외출 시간은 2.4의 생활 패턴 분석(요일·시간대별 귀가 시각)으로 추정한다.

**검증 방법**

1. 외출 시간: 30분 / 1시간 / 2시간 / 4시간 / 8시간
2. 외기 온도: 28 / 32 / 35 °C (실측은 해당 날씨의 날로 분류)
3. 전략 3가지: 끄기 / 셋백(+2~3 °C) / 같은 온도 유지
4. 측정: 클램프 실측 에너지(kWh), 귀가 후 쾌적 범위 회복 시간, 귀가 시 습도
5. 결과: 외기 온도별 T\* 표 → 제어 규칙에 반영

Isaac Sim 환경 모델에는 **벽체 열용량**과 **인버터 부분부하 효율 곡선**이 반영되어야 의미 있는 결과가 나온다.

### 2.3 데이터 수집

**수집 항목 (예시 스키마)**

| 필드 | 출처 | 주기 |
|---|---|---|
| timestamp | — | 1 s (원본), 1 min (집계) |
| device, irms, power_est, state | 클램프 | 1 s |
| t_in, rh_in | DHT22 | 10 s |
| t_out, rh_out | 기상청 API | 1 h |
| pm25_out | 에어코리아 API | 1 h |
| occupancy, zone | mmWave | 1 s |
| mode, setpoint | 제어기 로그 | 이벤트 |

- 전력 추정: P ≈ V × Irms × 역률(추정값)
- **실측 기간: 실제 원룸에서 1~2주 이상** (팀원 방 하나라도)
- 시뮬레이션: 가상 거주자의 하루 일정(페르소나)으로 동일 스키마 데이터 생성 → 분석 코드 선검증

### 2.4 분석 단계

1. **기기별 운전 구간 분리**: 상태 머신 결과로 RUN / FAN_ONLY 구간을 잘라냄
2. **시간대별 사용 확률**: 요일 × 시간 히스토그램
3. **외기 온도별 회귀**: 일일 에너지 vs 일평균 외기 온도
4. **예측**: 귀가·기상 시각, 내일 에너지
5. **이상 감지**: 상태별·외기 조건별 기준 전력 대비 편차

### 2.5 외기 온도별 회귀 분석

| 분석 | 변수 | 모델 |
|---|---|---|
| 에어컨 일일 에너지 | 일평균 외기 온도 또는 냉방도일(CDD) | 선형 → 필요 시 2차 다항식 |
| 에어컨 순간 전력 | 실내·외 온도차 (ΔT), 설정 온도 | 선형 회귀 (인버터 부분부하 특성 확인) |
| 제습기 가동률·에너지 | 실내·외 절대습도 | 선형 회귀 |
| 전체 전력 | 외기 온도 | U자 형태 확인 (냉방·난방 구간) |

### 2.6 연결 실험

| 실험 | 비교 | 측정 |
|---|---|---|
| 외출 시 에어컨 (2.2 가설 검증) | 셋백(설정 온도 상향 유지) vs 끄기 vs 동일 온도 유지, 외출 시간 × 외기 온도 | 클램프 실측 에너지, 귀가 시 온·습도 회복 시간 |
| 수면 중 에어컨 | stay(설정 고정 유지) vs 꺼짐 예약 vs on/off 반복 | 실측 에너지, 수면 중 온도 이탈 |
| 제습 역할 분담 | 에어컨 단독(낮은 설정) vs 에어컨 높은 설정 + 제습기 약 | 실측 에너지, 습도 |

### 2.7 평가 지표 추가

- 상태 판정 정확도 (실측 대비)
- 수동 조작 감지율
- 셋백·stay 전략의 에너지 절감량 (실측)
- 외기 온도 회귀 모델 오차 (예: R², MAE)

### 2.8 참고 논문 (2021.10 이후)

**인버터 운전·셋백**

1. *Experimental Study of the Model Predictive Control for a Residential Split Air Conditioner*, ScienceDirect, 2022
   — 인버터 벽걸이 에어컨을 on/off 제어하면 24 °C 연속 운전보다 20.12% 더 소비. MPC는 7.06% 이상 절감.
2. *Long-Term Field Testing of the Accuracy and HVAC Energy Savings Potential of Occupancy Presence Sensors in a Single-Family Home*, Energy and Buildings, 2024
   — 냉방 시즌 셋백으로 일일 최대 35% 절감. 외출이 길고 외기 온도가 높을수록 절감 증가. (단독주택 중앙공조)
3. *Occupancy-Based Controls for an All-Electric Residential Community in a Cold Climate*, NREL, IEEE PES GM 2022
   — 재실 기반 셋백 제어로 건물별 1~20% 절감 (시뮬레이션).
4. *A systemic review to improve the intermittent operation efficiency of air-conditioning and heating system*, J. Building Engineering, 2022
   — 간헐 운전 시 벽·바닥 축열이 재가동 부하를 키움.

**설정 온도·실사용 효율**

5. Niknami et al., *An experimental study on the effect of room setpoint temperature, and evaporator/condenser fouling on performance of a ductless split type air conditioner*, Energy and Buildings, Vol. 322, 2024
   — 설정 1 °C 상향 시 약 57 W, 연간 약 279 kWh 절감. 증발기 코일 30% 막힘 시 EER 13.5% 하락.
6. *Experimental evaluation of SEER and SCOP deviations in inverter air conditioners under standard test modes and real-life user settings*, Energy and Buildings, 2025
   — 에너지 라벨이 실사용 효율을 과대평가할 위험 → 실측 필요.

**외기 온도별 에너지 패턴**

7. *A quantitative comparison of different methods for air conditioning energy consumption prediction in residential buildings*, ScienceDirect, 2024
   — 스마트 소켓 실측. 냉방 시즌 일일 에어컨 에너지와 외기 온도의 선형 관계가 뚜렷. 전체 전력은 외기 온도에 대해 U자 형태.
8. *Assessing disparities in air conditioning operation across Southern California*, PMC, 2026
   — 스마트미터 데이터에서 전력-온도 관계로 냉방 구간 식별.
9. *The impact of air conditioning on residential electricity consumption across world countries*, ScienceDirect, 2025
   — 냉방도일(CDD) 기반 비선형 회귀 구조.

> 다이킨·삼성·한전 실험은 논문이 아니므로 발표 자료에는 "제조사 실험(참고치)"로 표기한다.
> **원룸 벽걸이 인버터 에어컨의 셋백 vs 끄기를 실측 비교한 연구는 찾지 못함 → 본 프로젝트의 기여 포인트.**
