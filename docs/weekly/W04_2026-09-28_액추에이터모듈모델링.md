# W04 주차 계획서 — 액추에이터 모듈 모델링

- **기간:** 2026-09-28(월) ~ 2026-10-04(일)
- **단계:** Phase 1. 시뮬레이션 환경
- **개정:** 2026-09-12 · v2.0 — 액추에이터 4종 → **5종** (책상 스탠드 추가), Effort Sensor 부착

## 1. 주차 목표
액추에이터 **5종**(천장조명·책상스탠드·환기팬·블라인드·창문)을 Isaac Sim 프림과 조인트로 모델링하고,
창문 조인트에 **Effort Sensor를 부착해 반력을 읽을 수 있는 상태**로 만든다.

## 2. 세부 태스크

| ID | 태스크 | Isaac Sim 표현 | 예상 |
|---|---|---|---:|
| T4.1 | `lighting_module/ceiling_led_light` 생성 | Light Prim (intensity 0–100 %) | 3h |
| **T4.1b** | **`lighting_module/desk_lamp` 생성** — 밝기 + **색온도 제어** | Light Prim (intensity + colorTemperature) | 3h |
| T4.2 | `blind_module` (slats + `blind_joint`) | Revolute Joint 0–90° | 5h |
| T4.3 | `window_module/window_panel` 개폐 조인트 | **Prismatic** (미닫이), 개방률 0–100 %, 레일 축 = T3.3 정의 축 | 4h |
| **T4.3b** | **창문 조인트에 Effort Sensor 부착** + Contact Sensor 연결 · 반력 읽기 실증 | `EffortSensor` 인스턴스 | 4h |
| T4.4 | `ventilation_module` (housing + blades) | Revolute Joint, 0–2000 rpm | 4h |
| T4.5 | `occupancy_object` (사람 프록시) 배치 — **desk/bed 두 위치로 이동 가능** | 이동 가능 프림 | 3h |
| T4.6 | `config/actuator_limits.yaml` 작성 (위치·속도·**토크** 제한) | 설정 파일 | 2h |

> ### ⚠️ T4.1b 구현 시 함정 — 색온도는 명시적으로 켜야 한다
>
> ```python
> light.CreateEnableColorTemperatureAttr(True)   # ← 이걸 빼면
> light.CreateColorTemperatureAttr(2700.0)       # ← 이 값이 무시된다
> ```
> `enableColorTemperature`의 기본값은 **False**다. 수면/공부 모드 구현 시 "값은 넣었는데 색이 안 바뀐다"로
> 시간을 낭비하기 쉬운 지점이다.

> ### 💡 데모 영상 품질 — emissive 재질을 함께 켠다
> Light Prim만 켜면 **방은 밝아지는데 조명 기구 자체는 어둡게 남아** 영상에서 어색하다.
> 메시의 emissive 재질을 `intensity`와 연동해야 전구가 빛나 보인다.

## 3. 산출물
- `assets/actuator_models/` — **5종** 액추에이터 모듈
- `config/actuator_limits.yaml`
- 액추에이터 사양표 (조인트명 / 타입 / 범위 / 최대속도 / 최대토크)
- **Effort Sensor 반력 읽기 로그** (패널을 벽에 밀어붙였을 때의 값 변화)

## 4. 완료 기준 (DoD)
- [ ] **5종** 액추에이터가 Isaac Sim GUI에서 수동 슬라이더로 움직인다
- [ ] 각 조인트에 위치·속도·토크 제한이 설정되어 범위를 넘지 않는다
- [ ] 천장 조명·스탠드 intensity 변경이 실내 밝기에 시각적으로 반영된다
- [ ] **스탠드 색온도를 2700 K ↔ 6500 K로 바꾸면 화면 색이 실제로 변한다**
- [ ] ⭐ **창문을 장애물에 밀어붙이면 Effort Sensor 값이 상승하고, Contact Sensor가 접촉력을 보고한다**
- [ ] 사람 프록시를 desk / bed 위치로 옮기면 해당 트리거 영역이 반응한다
