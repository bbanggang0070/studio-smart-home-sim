## 5. 리스크 / 대응
| 리스크 | 대응 |
|---|---|
| 브릿지 스레드와 물리 스텝 동기화 문제 | 물리 콜백 내에서만 조인트 쓰기, 명령은 큐로 전달 |
| QoS 불일치로 토픽 미수신 | 센서 = BEST_EFFORT, 명령·상태 = RELIABLE. **단 `window_motor_current`(50 Hz)는 BEST_EFFORT/depth 5** |
| **토크 상한 변경이 조인트 드라이브에 반영되지 않음** | Isaac Sim 조인트 드라이브의 `maxForce` 속성을 런타임에 쓸 수 있는지 W06에서 확인. 불가 시 목표 속도 제한으로 대체 |
| 토픽 25개로 늘어 연결 누락 발생 | 점검표로 1:1 대조. `ros2 topic list \| wc -l`로 개수 확인 |
| **로컬 컷오프가 기동 피크에서 오작동** | 임계값을 상위 판정(0.25 A)보다 훨씬 보수적으로(1.80 A) 설정. 로컬은 **최후의 방어선**이지 주 판정자가 아니다 |
