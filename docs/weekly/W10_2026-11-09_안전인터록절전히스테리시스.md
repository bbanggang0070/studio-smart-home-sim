## 4. 완료 기준 (DoD)

### 센서리스 안전
- [ ] **리플 위치 추정 오차 ≤ 5 mm** (1회 왕복 누적), 하드 스톱에서 재동기화 확인
- [ ] **Zone A–D 전환이 설계값대로 100 % 정확히 라벨링**된다
- [ ] **토크 프로파일이 실제 조인트 구동력에 반영**된다 (기동 구간 토크 > 주행 구간)
- [ ] ⭐ **강체 장애물 끼임 시 감지 성공 · 최대 접촉 반력 ≤ 100 N**
- [ ] ⭐ **연질·탄성 물체에서도 감지 성공** — 가장 어려운 조건
- [ ] ⭐ **엔드존(씰 압착)을 끼임으로 오판하지 않는다** — 정상 폐쇄 20회 연속 무오검출
- [ ] **엔드존 직전에 끼임을 주입하면 검출된다** — 미검출 방지 확인
- [ ] 끼임 후 50 mm 반전 → `SAFETY_HOLD` 진입 → 2회 반복 시 방향 잠금
- [ ] MANUAL 모드에서도 끼임 감지가 동작한다
- [ ] ⭐ **제어기 노드를 죽인 상태에서도 로컬 컷오프가 창문을 정지시킨다** (2계층 분리 증거)
- [ ] **상위 무응답 500 ms 경과 시 로컬이 정지 상태를 유지한다**

### 실험 하네스
- [ ] ⭐ **시나리오 17개 × baseline × 반복 = 99개 조합이 전개된다**
- [ ] **무인으로 연속 10회 이상 실행되고 중간에 죽지 않는다**
- [ ] **같은 시드로 2회 실행 시 결과가 동일하다** (재현성)
- [ ] `pass_criteria`가 자동 평가되어 PASS/FAIL이 기록된다
- [ ] `results/summary.csv`에 지표 8종이 집계된다

### 절전·히스테리시스
- [ ] 무재실 60 s 경과 시 전 액추에이터가 절전 상태로 전환
- [ ] 온도가 27~29 °C를 오갈 때 창문/팬 토글이 발생하지 않음
- [ ] 습도가 65~72 %RH를 오갈 때 토글이 발생하지 않음
- [ ] 조명 모드가 경계 시각에서 반복 전환되지 않음
- [ ] 단위 테스트 전체 통과

## 5. 리스크 / 대응

| 리스크 | 영향 | 대응 |
|---|---|---|
| ⭐ **하네스가 주말까지 안 끝남** | **W11–W12 붕괴** | W09에 골격 착수 완료 전제. 월–수에 집중 배치. 수요일까지 안 되면 **Tier 3을 즉시 선택 과제로 강등**하고 범위를 줄인다 |
| ⭐ **저속 구간(토크 55 %)에서 끼임 미검출** | 안전 지표 미달 | 토크 하한을 55 → 65 %로 상향. **반력이 커지는 대신 검출률을 확보**한다. 최종값은 W12에서 스윕하여 확정 |
| **엔드존과 끼임이 구분되지 않음** | 오검출 또는 미검출 | 3조건(위치·기울기·지속거리) 중 **"발생 위치" 조건이 최종 판별자**. 엔드존은 행정 종단으로 한정되므로 중간 지점의 완만한 상승은 무조건 끼임으로 처리 |
| **연질 물체에서 반력 상승이 너무 완만** | 감지 실패 | 속도 저하 조건(`speed_drop_ratio`)의 비중을 높인다. 전류만으로 안 되면 속도가 판별한다 |
| **리플 카운팅이 드리프트로 발산** | 위치 추정 붕괴 | 하드 스톱 재동기화 필수. `miscount_rate_pct`를 0.3 % 이하로 제한.<br>**백업 플랜:** 오차가 목표(5 mm)를 넘으면 **홀센서(A3144)+자석 2개(약 3,000원)** 추가 (`hall_reference_enabled: true`) |
| **적응형 임계값이 끼임 상태를 학습해버림** | 감지 무력화 | `exclude_pinch_runs: true` — 끼임이 발생한 주행은 학습에서 반드시 제외 |
| 히스테리시스 폭이 너무 넓어 쾌적성 저하 | 환경 유지율 하락 | 밴드 폭을 파라미터화해 W11 실험에서 비교 |
