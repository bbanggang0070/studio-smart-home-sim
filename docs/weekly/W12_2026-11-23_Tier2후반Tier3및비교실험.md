## 1. 주차 목표

**Tier 2 후반 4개(C5–C8)** 를 3군 비교로 완료하고, **Tier 3 4개**로 시스템 성숙도를 입증한다.
아울러 **센서리스 파라미터 스윕**과 **조도 모델 대조**로 결과의 신뢰 근거를 확보한다.

## 2. 실험 대상

### Tier 2 후반 (A/B/Proposed × 3회 = 36회)

| ID | 충돌 제약 | 기대 협조 동작 | 핵심 확인 |
|---|---|---|---|
| C5 | 냉각 ↔ 수면 소음 | **창문 우선**, 팬은 600 rpm 상한 | 재실 영역(침대) 판정이 정책을 바꿀 것 |
| C6 | 제습 ↔ 난방 손실 | 창문 **간헐 개방**(20 % × 60 s) + 팬 저속 | 습도 70 % 이하 도달 · 온도 하락 ≤ 2 °C |
| C7 | 절전 ↔ 우천 안전 | 절전 중에도 **창문 폐쇄 실행** | 안전이 절전보다 우선함을 증명 |
| **C8** ⭐ | 환기 ↔ 외기 공기질 | 등급별 **단계적** 창문·팬 제한. **매우나쁨에서 팬 정지** | **C1과 정반대 동작** — 팬이 대체 수단이 되지 못함 |

### Tier 3 (Proposed 단독 × 3회 = 12회) — **선택 과제**

| ID | 상황 | 기대 동작 | 핵심 확인 |
|---|---|---|---|
| X1 | 4중 제약 (고온+고습+우천+수면) | 수면 상한 내 최선 운전 + 블라인드 야간 개방 | **제약 위반 0회** |
| X2 | 모든 환기 경로 차단 | `INFEASIBLE` 판정 + 보고 | **헛구동 0회** |
| X3 | 조도 센서 무효값 | 페일세이프 — 조명 정책만 동결 | 안전·온도 기능 유지 |
| X4 | 수동 명령 + 끼임 | 감지 → 정지 + 거부 사유 발행 | 최대 접촉 반력 ≤ 100 N |

**총 실행: 36 + 12 = 48회** (Tier 3 제외 시 36회)

## 3. 보조 검증 3종 — 결과의 신뢰 근거

| # | 검증 | 목적 | 예상 |
|---|---|---|---:|
| **① 센서리스 토크 스윕** | Zone B 종료 토크를 **45 / 55 / 65 / 75 %** 로 바꿔가며 **감지율 vs 최대 반력** 트레이드오프 곡선 확보 | "55 %는 왜 그 값인가"에 데이터로 답한다 | 5h |
| **② 물체 강성 민감도** | 강체 / 연질 / 탄성 3종 × 각 10회 끼임 | **연질 물체가 가장 어려운 조건** — 여기서 실패하면 한계로 명시 | 4h |
| **③ 조도 모델 대조** | 저해상도 카메라 상대 휘도 vs 해석 모델 (오프라인 1회) | "계산값이라 못 믿겠다"는 질문에 데이터로 답한다 | 4h |

> **① 스윕이 특히 값어치가 크다.** 토크를 낮추면 반력은 작아지지만 신호 대 잡음비가 나빠져 감지가 어려워진다.
> 이 **정면 트레이드오프를 곡선으로 제시**하면 설계값 선택이 임의가 아님을 보일 수 있다.

## 6. 완료 기준 (DoD)
- [ ] **C5에서 팬 RPM이 600을 초과하지 않으면서 온도가 하강한다**
- [ ] **C6에서 습도 70 % 이하 도달 + 온도 하락 2 °C 이내**
- [ ] **C7에서 절전 중에도 창문이 폐쇄된다** — 안전 > 절전 증명
- [ ] ⭐ **C8에서 등급이 나빠질수록 창문·팬이 단계적으로 줄고, 매우나쁨에서 팬이 정지한다**
- [ ] ⭐ **C1(팬 최대)과 C8(팬 정지)의 대비가 한 장의 그래프로 제시 가능하다**
- [ ] **X2에서 `INFEASIBLE`이 발행되고 헛구동이 0회다**
- [ ] **X1에서 제약 위반이 0회다**
- [ ] ⭐ **토크 스윕 곡선이 확보되어 55 % 선택의 근거가 데이터로 제시된다**
- [ ] ⭐ **3종 물체 모두에서 감지 성공** — 실패 시 한계로 명시하고 조건을 기록
- [ ] **조도 해석 모델의 오차가 수치로 제시된다**
- [ ] **249회** 전량 데이터셋이 결측 없이 확보됨

## 7. 리스크 / 대응
| 리스크 | 대응 |
|---|---|
| **일정 압박으로 Tier 3을 못 돌림** | ✅ **애초에 선택 과제로 설계됨.** Tier 1+2(**87회**)만으로 발표 피드백 요구는 충족된다. 잘라내되 **보고서에 사유를 명시**한다 |
| **연질 물체 감지 실패** | 은폐하지 않는다. **"연질 물체는 반력 상승이 완만해 검출이 어렵다"** 를 한계로 기술하고, 속도 저하 조건의 기여를 분석해 제시 |
| **토크를 낮추면 감지가 안 되고 높이면 반력이 초과** | 두 조건을 동시에 만족하는 구간이 없을 수 있다. 그럴 경우 **"100 N 이하 ∧ 감지율 100 %"가 양립 불가한 영역**을 곡선으로 보이는 것 자체가 결과다 |
| **조도 모델 오차가 과대(>30 %)** | 원인(톤매핑·노출·간접광)을 분석해 기술. 제어 정책 검증에는 영향이 없음을 논증 |
| 배치 실행 중 크래시 | 실패 조합만 재실행하는 resume 기능 활용 |
