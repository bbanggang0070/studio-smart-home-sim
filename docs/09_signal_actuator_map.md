## 1. 센서 7종 — 무엇을 감지하고 무엇을 내보내나

| # | 센서 (부품) | 감지하는 것 | 출력 (토픽 · 주기) | 계산해서 얻는 것 |
|---:|---|---|---|---|
| 1 | **온습도** (DHT22) | 실내 온도 · 상대습도 | `temperature` °C · `humidity` %RH · 10 Hz | 절대습도 · **이슬점** · 외기온과 합쳐 **창 표면온도 → 결로 여유** |
| 2 | **밝기** (BH1750) | 천장에서 본 실내 조도 | `illuminance` lux · 10 Hz | **책상면 조도 추정** (천장 조도 + 스탠드 명령값) · 고장 시 태양 위치로 계산 |
| 3 | **레이더 재실** (LD2410 mmWave) | 0.75 m 구간(0–8번, 최대 약 6 m)별 **움직임 · 정지(호흡) 신호 세기** | 구간별 신호 → `occupancy` · `occupant_zone` | **판정 창 증거** · **위치**(책상 2–3 / 침대 5–6번 구간) · **수면** · 문 센서 고장 감지 |
| 4 | **문 열림** (리드 스위치) | 현관문 열림 / 닫힘 | `door_contact` Bool · 변경 시 | **재실 판정 시점** · 귀가 |
| 5 | **창문 모터 전류** (ACS712) | 창문 모터에 흐르는 전류 | `window_motor_current` A · 50 Hz | **창문 위치**(리플 1개 = 0.209 mm) · **끼임** |
| 6 | **미세먼지** (PMS7003) | 실내 PM2.5 | `pm25` µg/m³ · 1 Hz | **실내 공기 상태** · **원인 구분**(요리 / 가습기 물방울 / 외기 / 원인 미상) · 청정기 효과 확인 |
| 7 | **후드 아래 온도** (DS18B20) | 레인지 위로 올라오는 조리 열기 | `hood_temperature` °C · 1 Hz | **요리 시작 · 끝**(가스 · 빌트인 포함) · **불 켜고 외출 경고** |

## 3. 신호를 조합해 판단하는 상황

| 판단 | 어떤 신호를 조합하나 | 결과 |
|---|---|---|
| **재실 / 외출** | **문 열림 → 닫힘 → 3분 판정 창**: 방 안쪽 레이더 움직임 · 기기 조작 = 강한 증거 / 벽 구간 신호 = 약한 증거 · Wi-Fi 끊김 = 외출 증거 | 재실 유지 / 빈방 유지 (다음 문 열림까지) |
| **위치** | 레이더 구간 (책상 2–3 · 침대 5–6) | 자동 모드 → 공부 / 수면 |
| **수면** | 침대 구간 정지 신호 + 밤 시간 + 조명 꺼짐 | 수면 모드 |
| **요리** | **후드 아래 온도 상승**(가스 · 빌트인 포함) ∨ 쿡탑 전력(플러그형) — 켜는 즉시 · 미세먼지는 연기 세기 | 후드 · 급기 · 청정기 |
| **미세먼지 원인** | 후드 아래 온도 × 실내 미세먼지 × 가습기 · 외기 | 열 + 연기 → 요리(후드) / 열만 → 수증기 / 연기만 → 가습기 · 외기 · 원인 미상(**후드 끔**, 청정기) |
| **불 켜고 외출** | 빈방 판정 + 후드 아래 온도 높음 · 쿡탑 전력 | 즉시 알림 · 플러그형 인덕션 전원 차단 |
| **빨래 건조** | 세탁기 탈수 종료 + 습도 완만 상승 · 또는 사용자 선언 | 최우선 목표 = 건조 시간 |
| **결로 위험** | 온습도 + 외기온 → 이슬점 vs 창 표면온도 | 가습 중단 · 실링팬 역회전 · 블라인드 개방 · 제습 |
| **기본 환기** | 재실(문 + 레이더) · 모드 — **CO₂를 재거나 계산하지 않음** | 흡기팬(필터) · 창문 소폭으로 1인 기준 환기량 상시 공급 |
| **샤워** | 습도 5분 +8 %p 급상승 · 후드 아래 온도 정상 · 가습기 꺼짐 (+ 직전 레이더 무신호 = 욕실) | 배기 + 균형 급기 · 제습 강화 |
| **환기로 제습 가능?** | 실내 이슬점 vs 바깥 이슬점(기상청) | 바깥이 2 °C 이상 건조할 때만 배기 · 창문으로 제습 — 아니면 에어컨 · 제습기 |
| **강우 · 외기 오염** | 기상청 강우 · 에어코리아 + 실내 PM 교차 | 창문 금지 · 필터 급기 |
| **기기 이상 · 직접 조작** | 명령 vs 기기 전력 · 환경 변화 | 재시도 · 다음 수단 · 30분 자동 제어 보류 |
| **전력 한도** | 기기 전력 합계 ≥ 한도 90 % | 미뤄도 되는 기기부터 줄임 |
| **끼임** | 창문 모터 전류 급상승 + 속도 저하 | **즉시 정지 · 50 mm 반전** |
| **귀가 예측** | 문 · Wi-Fi 기록 → 귀가 시각 분포 + 방의 열 모델 | 미리 냉방 시각 · 켜두기 vs 끄기 |

## 4. 판단 결과를 어떻게 합치나 — 우선순위

같은 기기에 여러 요구가 걸리면 **위에 있는 것이 이긴다.**

```text
1  안전            끼임 · 비 · 외기 오염 · 전력 한도 · 기기 보호(압축기 3분 등)
2  건강 · 재산     요리 연기 · 샤워 습기 · 기본 환기 미달 · 결로 위험
3  최우선 목표     빨래 건조 등 — 정한 감수 한도 안에서만 다른 목표를 양보시킴
4  절전            외출 · 빈방
5  생활 모드       일반 · 공부 · 야간 · 수면 · 외출 — 소음 한도 · 목표값
6  쾌적            온도 · 습도 · 기본 환기 · 결로 경고
7  밝기
```

- **금지·강제**(예: 비 → 창문 0 %)는 위 단계가 이긴다
- **상한**(예: 수면 → 팬 600 rpm 이하)은 가장 낮은 값을 쓴다
- **필요량**(예: 환기 40 % vs 제습 60 %)은 가장 큰 값을 쓴다
- 같은 목표는 **전기를 적게 쓰는 수단부터** 쓴다 — 냉방이면 블라인드 → 창문 → 실링팬 → 팬 환기 → 에어컨

## 5. 액추에이터 11종 — 무엇을 보고 어떻게 움직이나

### 설치하는 장치 (5)

| 액추에이터 | 주로 보는 신호 | 이렇게 움직인다 | 이럴 땐 하지 않는다 / 제한 |
|---|---|---|---|
| **창문** (랙-피니언 · 센서리스) | 온도 · 외기온 · 재실 · 결로 여유 · 강우 · 외기 PM | 바깥이 더 시원하면 냉방 환기 · 기본 환기(외기 양호 · 비 X · 냉방 X이면 10 %) · 겨울 결로 때 짧게 간헐 환기 · 후드 가동 시 10–20 % 열어 급기 | **비 · 외기 오염 나쁨 · 에어컨 냉방 중(10 % 초과) · 외출(보안)** · **끼임 → 즉시 정지 · 반전** |
| **블라인드** (SG90) | 조도 · 온도 · 일사 · 결로 여유 · 모드 | 700 lux 넘으면 75° 차광 · 250 lux 아래면 열어 채광 · 더울 땐 **가장 먼저 닫아 열 차단** | 결로 위험이면 45°(경고)/0°(위험)로 열기 · 야간 모드는 닫힘(프라이버시) — 결로 위험이 이김 |
| **배기팬** | 습도 · **실내 · 바깥 이슬점** · 외기 PM · 샤워 | **샤워 습기 배출(원인 지점)** · 바깥이 더 건조할 때 제습 배기 · 항상 흡기팬 · 창문과 짝(균형) | **바깥 이슬점이 실내 − 2 °C보다 높으면 제습 배기 안 함**(비 오는 여름 — 습기 유입) · **외기 오염 시 급기 없는 배기 금지** · 수면 중 600 rpm 이하 |
| **책상 스탠드** | 위치(책상) · 모드 · 책상 조도 추정 | 공부: 600 lux · 5500 K / 수면: 2700 K | 더울 때 천장 조명 대신 **스탠드로 국부 보충** |
| **흡기팬 + 필터** | 재실 · 모드 · 외기 PM · 후드 · 배기팬 가동 | **재실 기본 환기의 주 수단** · **창문을 못 쓸 때(비 · 외기 오염 · 냉방) 후드 · 배기팬과 짝을 이루는 급기** · 외기 오염 시 걸러서 들여 양압 유지 | 수면 중 700 rpm 이하 |

### 연결하는 보유 가전 (6)

| 액추에이터 | 주로 보는 신호 | 이렇게 움직인다 | 이럴 땐 하지 않는다 / 제한 |
|---|---|---|---|
| **실링팬 (조명 일체형)** | 조도 · 모드 · 온도 · 결로 여유 | **조명**: 조도 · 모드에 맞춰 디밍 / **팬 정회전**: 체감 냉방 → 에어컨 설정 +1 °C 완화 / **역회전**: 겨울 창 표면을 데워 결로 방지 · 가습 상한 올림 | 더울 땐 조명 밝기 상한(발열) · 수면 중 약풍 |
| **에어컨** (리모컨 신호) | 온도 · 습도 · 귀가 예측 · 기기 전력 | 사다리 마지막 냉방 · **여름 제습** · **샤워 · 비 오는 날 요리 후 제습 강화(설정 −1 °C)** · **귀가 전 미리 냉방** · 짧은 외출은 온도 올려 켜두기, 긴 외출은 끄기 | 창문 10 % 초과면 냉방 안 함 · 수면 중 약풍 · **명령 후 10초 안에 전력 확인 → 안 되면 재시도 2회 → 다음 수단** |
| **제습기** | 습도 · 결로 여유 · 계절 · 외출 · 빨래 | 겨울 제습 · 결로 대처 · 외출 중 곰팡이 방지(70 %) · **빨래 건조 · 샤워 후 에어컨과 함께** (전력이 빠듯하면 요리 끝난 뒤 투입) | **가습기와 동시 금지** · 수면 중 금지(소음) · 여름 평소엔 에어컨 제습 우선(발열 480 W) · 물통 가득 감지 |
| **가습기** | 습도 · 결로 여유 · 외기온 · 실내 PM | 겨울 건조할 때 가습 · 초음파식이 미세먼지를 만들면 정수 사용 · 교체 안내 | **상한 = 결로가 안 생기는 습도**(외기 0 °C ≈ 58 %, 실링팬 역회전 시 64 %) · 결로 위험이면 끔 · 제습기와 동시 금지 |
| **공기청정기** (리모컨 신호) | 실내 PM · 요리 · 외기 오염 | PM 높으면 가동 · 요리 중 3단 · 외기 오염 시 | 수면 중 1단 · 명령 후 전력으로 확인 |
| **레인지후드** | **후드 아래 온도** · 쿡탑 전력 · 실내 PM · 외기 PM | 불을 켜는 순간 **연기 나기 전에 가동**(가스 · 빌트인 포함) · 요리 후 5분 더 · **열 없이 미세먼지만 오르면 켜지 않음** | 외기 오염 시 **약 · 강 · 끔 중 실내 PM이 가장 낮을 단수를 예측해 선택** · **보충 급기 필수** · 전력 한도에서도 끄지 않음 |

## 6. 예시 3개 — 신호가 어떻게 기기로 이어지나

### 예시 1 · 여름 저녁, 외기 미세먼지 나쁨 + 요리

```text
신호   후드 아래 온도 급상승 (가스레인지 — 전력 신호 없음)  ·  외기 PM 52 (나쁨)  ·  실내 PM 상승
판단   요리 시작 (열 + 연기 → 요리)  ·  외기 오염
결정   안전: 창문 금지 · 급기 없는 배기 금지
       건강: 후드 — 3안 예측 → "약" (강은 음압으로 오염 외기 유입이 더 큼)
결과   후드 약 · 흡기팬 100 %(필터 보충 급기) · 청정기 3단 · 창문 0 % · 배기팬 정지
확인   후드 · 청정기 전력 확인 → 요리 끝나면 후드 5분 더 → 원래대로
```

### 예시 2 · 겨울 밤, 건조한데 창에 물이 맺힐 것 같다

```text
신호   실내 21 °C · 30 %RH  ·  외기 −5 °C  ·  블라인드 닫힘(야간 모드)
판단   건조 → 가습 필요  /  결로 계산: 가습 상한 53 %
결정   쾌적: 가습기 ON (상한 53 %)  →  실링팬 역회전으로 창 표면 가온 → 상한 59 %
       결로 경고가 뜨면 블라인드 45° (시선은 가리고 공기는 통하게)
결과   가습기 · 실링팬 역회전 · 제습기 OFF (동시 금지)
```

### 예시 3 · 여름, 외출했다가 귀가

```text
신호   문 열림 → 닫힘 → 3분 동안 방 안 신호 없음 (휴대폰은 집에 두고 감)
판단   외출 확정 (Wi-Fi는 증거로 쓰지 않으므로 3분 만에)
결정   절전: 조명 · 팬 정지 · 창문 닫힘(보안)  /  에너지: 예상 외출 6시간 → 에어컨 끄기
       귀가 예측: 19:00 전후 → 기대비용이 가장 낮은 18:15에 미리 냉방
결과   문 열림(귀가) 즉시 직전 모드 복귀 · 실내는 이미 27 °C 이하
```

### 예시 4 · 장마철 저녁, 비 오는 날 샤워

```text
신호   비 (기상청)  ·  외기 24 °C · 95 % (이슬점 23 °C)  ·  에어컨 냉방 중
       레이더 15분 무신호(욕실) → 습도 5분에 60 → 78 %  ·  후드 아래 온도 정상  ·  가습기 꺼짐
판단   샤워 (요리 · 가습기 아님)  /  실내 이슬점 25 °C > 바깥 23 °C + 2 → 지금은 배기가 이득
결정   안전: 창문 금지(비)
       건강 · 재산: 배기팬 강 + 흡기팬 동시(창문 대신 급기) · 에어컨 설정 −1 °C · 제습기 허용
결과   10분 뒤 실내 이슬점이 바깥과 1 °C 이내 → 배기 멈춤 → 에어컨 · 제습기가 나머지 처리
확인   30분 안에 습도 60 % 이하 → 기본 환기(흡기팬 25 m³/h)로 복귀
```
